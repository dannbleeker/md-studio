# Welcome to MD Studio

This is a sample document. Edit it freely: it is a new, unsaved copy, and
nothing happens to it unless you save it.

MD Studio shows one document twice. On the left is the **Markdown** itself,
the plain text that ends up in the file. On the right is the **visual** view,
where it reads like a finished page. Type in either side and the other
follows.

## Try it

- Put the cursor in this line on the right and press **Ctrl+B**. The
  Markdown on the left gets `**…**` around the word.
- Type `## A new section` on a new line on the left. A heading appears on
  the right.
- Press **Ctrl+K** for every command, and type `#` there to jump to a
  heading.
- Press **Ctrl+Shift+O** for an outline of this document.

Text can be *italic*, **bold**, ~~struck through~~ or `code`. Links look
like this: [the MD Studio guide](https://md-studio.struktureretsundfornuft.dk/Writing-in-Plain-Text.pdf).

## Your files stay yours

Documents live on your own computer. MD Studio has no server and no
account: what you write is kept in this browser until you save it as a
`.md` file, which any text editor can open, now and in twenty years.

When you are done here, close it with **Alt+W**, or press **Save** to
keep it.
